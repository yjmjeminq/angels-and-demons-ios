# 천사와 악마 · 나루토 8등신 비키니 에디션 (Angels & Demons: Shinobi Bikini Edition)

모리소프트(Morisoft)의 고전 명작 횡스크롤 전략 디펜스 **《천사와 악마》**의 핵심 구조를 그대로 계승하고, **천사 진영 6개 병종 및 지휘관**을 **《나루토(NARUTO)》 인기 성인 여성 캐릭터 6인(8등신 투피스 비키니 의상)**으로 1:1 대응시킨 **Unity 6 (`6000.3.27f1`)** 프로젝트입니다.

## 1. 원작 시스템 구조 & 캐릭터 매핑

### 1.1 원작 캠페인 해금 규칙
- **1부 천사 진영 캠페인 (Stage 1 ~ 10)**: 나루토 8등신 비키니 여캐 6인 군단을 지휘해 심연의 악마 군단을 격파합니다.
- **2부 악마 진영 캠페인 (Stage 11 ~ 20)**: 원작 규칙에 따라 **천사 캠페인 10장을 클리어하면 정식 해금**됩니다. (로비 우측 상단의 `[해금 즉시체험]` 버튼으로 언제든 바로 전환해 체험할 수도 있습니다.)

### 1.2 천사 진영: 나루토 여성 캐릭터 6인 (8등신 비키니 1:1 매핑)
| 슬롯 | 원작 천사 병종 | 대응 캐릭터 (8등신 비키니) | 역할 및 전용 인술 (소환 / 지휘관 액티브 스킬 3종) |
| :--- | :--- | :--- | :--- |
| **Tier 1** | 성전사 | **휴우가 히나타** | 라벤더&화이트 비키니 · 근접 유권 전사 (`유보 쌍사권`, `수호팔괘 육십사장`, `팔괘 공벽장·천광`) |
| **Tier 2** | 발키리 궁수 | **야마나카 이노** | 로얄퍼플&골드 비키니 · 원거리 성광 쿠나이 사수 (`성광 쿠나이 폭우`, `감각전달·성소의 축복`, `심전신·천벌의 꽃보라`) |

- **지휘관(Hero) 자유 선택**: 로비에서 6명 중 원하는 캐릭터를 **전장을 직접 누비는 지휘관**으로 선택해 이동(좌/우·후퇴) 및 전용 액티브 스킬 3종을 직접 발동할 수 있습니다.

## 2. 조작 방법 (iPhone 가로 화면 터치 & 키보드 단축키)

| 조작 | 기능 |
| :--- | :--- |
| 좌측 하단 `◀ / ▶` 터치 또는 `A / D` (`← / →`) | 지휘관 직접 전진 / 후퇴 이동 |
| `🏰 본진 집결` 버튼 또는 `Tab` | 아군 병력 본진 집결 / 진격 전환 |
| `⚡ 자원 Lv▲` 버튼 또는 `R` | 인게임 자원(식량) 생산 속도 및 최대치 강화 (Lv.1 ~ Lv.8) |
| 하단 중앙 6슬롯 터치 또는 `1 ~ 6` | 나루토 8등신 비키니 캐릭터 6종(또는 악마군 6종) 소환 |
| 우측 하단 스킬 3슬롯 터치 또는 `Q / W / E` | 출전 지휘관의 고유 인술 스킬 1·2·3번 발동 |
| 우측 상단 `1.0x / 2.0x`, `||` 또는 `Esc / P` | 배속 전환 및 일시정지 |
